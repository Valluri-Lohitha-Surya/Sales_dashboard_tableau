# 📊 Sales Dashboard | Tableau

An interactive **Sales Dashboard** developed using **Tableau** to analyze sales performance, profitability, customer behavior, and regional trends. This project transforms raw sales data into actionable business insights through interactive visualizations and dashboards.

---

## 📌 Project Overview

The objective of this project is to create an intuitive and visually appealing dashboard that enables users to monitor key business metrics, identify sales patterns, and make data-driven decisions.

The dashboard provides insights into:

* Overall Sales Performance
* Profit Analysis
* Customer Segmentation
* Regional Performance
* Product Category Analysis
* Monthly Sales Trends

---

## ✨ Features

* 📈 Interactive Sales Dashboard
* 💰 Sales, Profit, and Order KPIs
* 🌍 Region & State-wise Sales Analysis
* 📦 Category and Sub-Category Performance
* 🛍️ Top Selling Products
* 👥 Customer Segment Analysis
* 📅 Monthly Sales Trend Visualization
* 🎛️ Interactive Filters for Dynamic Analysis
